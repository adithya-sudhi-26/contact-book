PROJECT STATEMENT

## Problem Statement
People need a lightweight, offline way to store and retrieve personal contact information without relying on heavy internet-based applications or complex databases.

SCOPE OF THE PROJECT
This project is a terminal-based Contact Book CLI restricted to local machine usage. It handles basic CRUD (Create, Read, Update, Delete) operations for contact names, phone numbers, and email addresses, storing data persistently in a local JSON file.

TARGET USER 
- Students and developers looking for a fast, keyboard-only contact manager.
- Users who want to keep their contact data private and stored strictly on their local machine.

HIGH LEVEL FEATURES
- Add new contacts with phone and email validation.
- Display all saved contacts in a structured list.
- Search for specific contacts by name.
- Delete outdated or incorrect contact records.
- Persistent local storage using JSON.
