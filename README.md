 CONTACT BOOK PROJECT

This is my final project submission for the Python Essentials course. It is a command line contact book program that lets users store names, phone numbers, and emails.


 PROJECT DETAILS

The program saves data into a local JSON file called `contacts.json` so the data stays saved even after closing the terminal.


 FEATURES

Add new contact

View saved contacts

Search contact by name

Delete contact


 HOW TO RUN

1. Clone or download this repository.

2. Open terminal in the project folder.

3. Run the script using Python:

```bash
python main.py



 INSTRUCTIONS FOR TESTING

2. Select option `2` to verify the contact list starts empty.

4. Restart the application and press `2` again to verify that the JSON data persistence works and Ada Lovelace is still saved.
5. Select option `4` to test the deletion of the test record.
